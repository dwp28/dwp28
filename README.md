### 🎱 Spanish Snooker Cup 2026 — Live Results Platform
> Built for the **Spanish Snooker Federation** and used live at the **Copa de España de Snooker** (Madrid, October 2–4, 2026).

A real-time web app that **replaced the federation's manual Excel sheets**, letting players and spectators follow scores, group standings and the knockout bracket from their phones, while organizers manage everything from an admin panel.

- ⚡ **Real-time sync** with Supabase Realtime — scores update on every device without reloading
- 🔒 **Admin & read-only modes** — frame-by-frame score editing, schedules, YouTube stream links, bracket generation
- 🎯 **Automatic tie-breakers & brackets** following federation rules (matches won → frame difference → head-to-head)
- ☁️ **100% serverless & near-zero cost:** Vanilla JS + Supabase + Netlify, with a GitHub Actions cron keep-alive and a custom build step that keeps secrets out of the public repo
- 🤝 **My role:** requirements gathering, architecture design, and end-to-end development and deployment
